# Python FFCO license extractor


## ffco_license_extractor.py
This folder contains `ffco_license_extractor.py`, a Python version of the web extractor:

- Finds the highest `competitionId` by parsing `https://inscriptions.co-paca.info/`
- Fetches clubs from `inscription1.php?no={competitionId}`
- Fetches runners for each club using **POST** to `inscription2.php?no={competitionId}` with `club={clubId}`
- Enforces **1 request per second**
- Prints debug information to the console
- Writes `ffco_licenses_YEAR.json`

### Collect French Orienteering Federation licenses
To run the extractor, simply execute:

```bash
python ffco_license_extractor.py
```

It will create `ffco_licenses_YEAR.json` in the current directory.

### Update the http server
Copy the file to the http://androloloid.free.fr/oliveresults/ffco_licenses/getCategory.php"

### Test the file & http communication is working
`test_get_category.py` is a simple test script that sends a POST request to the server with a sample runner names and prints the response.
```bash
python test_get_category.py
```

# PHP code
The PHP code for the server is located in `getCategory.php`. It reads the JSON file generated by the Python script and returns the category for a given runner name.
